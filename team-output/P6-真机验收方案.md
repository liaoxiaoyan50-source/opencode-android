## 3. M1–M3 执行表（验收内容见 P3 §7.2 与 P1 §4，此处只写手册增量）

**ABI 口径裁定（release-ops 边界标注的正式回应，定稿）**：
- **真机 arm64（D4）为 C3 第 3 项与 M0-3 的最终验收口径**。x86_64-16k 镜像装 arm64 单 ABI full APK 预期 `INSTALL_FAILED_NO_MATCHING_ABIS`；即便 ARM 翻译层装上，其 exec/ptrace 语义不可信，结论不得采信。
- 模拟器项（CI job_smoke_16kb 与 D5）标注 **BLOCKED-真机验证**；CI 等价证据链 = Gate 1/1b 对齐 PASS + `PAGESIZE=16384` 断言 + `unzip -l full.apk | grep 'lib/arm64-v8a/lib'` 双库存在。**不采纳 x86_64 lib 注入方案**（需 native-builder 增产变体，越出本次范围令；如需机制级补验请主理人另派）。

**幻影进程 adb 三连（逐条复制执行，Android 12+，D2）**：

```bash
adb shell device_config set_sync_disabled_for_tests persistent
adb shell device_config put activity_manager max_phantom_processes 2147483647
adb shell settings put global settings_enable_monitor_phantom_procs false
```

- 生效核验：`adb shell device_config get activity_manager max_phantom_processes` → `2147483647`；观测杀手：`adb logcat | grep -i phantom`。
- 复现（解除前）：默认上限下连续 kill -9 引擎触发守护反复拉起子进程 → logcat 见 phantom 击杀 → 引擎被杀、引导页出现。
- Android 14+：优先用开发者选项内「停用幻影进程监控」类开关（名称含 phantom process，部分 ROM 提供）；无开关 ROM 走三连命令。解除后挂机 24h，逐时经 M1-5 forward 口径 curl `/global/health` 记录存活。

## 6. 验收结论模板与执行顺序

**执行顺序（不得颠倒）**：① CI 冒烟（workflow_dispatch，debug 兜底出包；四 gate PASS 日志按 P5 §7-③ 核验）→ ② 16KB 模拟器（job_smoke_16kb + D5，ABI 按 §3 裁定）→ ③ 真机矩阵 M0 → M1 → M2 → M3 → M4。硬前置：四 SHA256 填齐（P2b §7-1 / P5 §6 checklist），否则 ① 出不了包。

结论三态模板（每里程碑项一行）：

| 字段 | 说明 |
|------|------|
| 结论 | **PASS**（达标）/ **FAIL**（实测不达标，附复现步骤）/ **BLOCKED**（无法执行，必填归因） |
| BLOCKED 归因枚举 | B1 环境限制（如 §3 ABI 裁定）；B2 上游待办（SHA256，P2b §7-1）；B3 契约待裁（P4 §8-2/3/4）；B4 设备缺位（无 16KB 真机） |
| 留痕物编号 | `V-M<m>-<项>-<序号>`（如 V-M0-1-03 = M0-1 第 3 台真机探测日志），编号须在报告中可检索 |
| 兼容性结论 | 每机型一行：机型 / ROM / API / 页大小 / ExecMode 结论 / 是否阻塞发布 |

> 项目级放行口径：M0 全 PASS（或 BLOCKED 仅限 B1 且附等价证据链）→ 放行进入 M1；M0–M3 无未闭环 FAIL 且 M4 崩溃率达标 → 出具最终兼容性报告回传主理人。
